
\chapter{Requerimientos del Sistema}

Esta sección describe los requerimientos funcionales (RF) y no funcionales (RNF) del sistema FisioManager. Cada requerimiento se identifica con un código único, una descripción clara y un nivel de prioridad: \prAlta\ (imprescindible para el MVP), \prMedia\ (importante para la primera versión) o \prBaja\ (deseable, planificado para versiones posteriores).

\section{Requerimientos No Funcionales}

Los requerimientos no funcionales describen las propiedades de calidad del sistema. Se agrupan según la categorización ISO/IEC 25010. Las categorías aquí utilizadas (Escalabilidad, Privacidad y Disponibilidad) se presentan como secciones independientes para mayor claridad operativa, aunque en la norma ISO/IEC 25010 corresponden a subcaracterísticas de Eficiencia de Desempeño, Seguridad y Confiabilidad respectivamente.
